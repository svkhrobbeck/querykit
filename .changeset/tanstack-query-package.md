New package `@querykitjs/tanstack-query` (1.0.0): `listOptions`, `infiniteOptions`, `cursorOptions` and `detailOptions` build ready TanStack Query options from a `@querykitjs/web` resource — the query key from `resource.keys`, your fetcher, the parsed meta and the page params (both ways for cursors). Plain option objects, no hooks: the same call works with React, Vue, Solid and Svelte Query. Peers: `@tanstack/query-core ^5.0.0`, `@querykitjs/web ^4.1`.
